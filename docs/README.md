# Өөрийгөө таних MBTI SPA

Энэ нэг хуудаст апп нь Монгол хэлний 70 асуултаар хариултыг тооцож, дөрвөн хэмжээсийн давуу сонголтоос 16 төрлийн код гаргана. Төрлийн дэлгэрэнгүй танилцуулгыг өгөгдсөн профайлын сангаас харуулна.

## Хөгжүүлэлтийн бүтэц

- js/router.js, js/routes.js: hash router болон хуудасны маршрутууд
- js/pages/: нүүр, тест, төрөл, үр дүнгийн тусдаа хуудас
- js/layouts/pageLayout.js: нийтлэг хуудасны үндсэн layout
- js/components/navbar.js: навигацийн цэс
- js/i18n/: Монгол/Англи орчуулга ба хэлний сонголтыг хадгалах
- assets/data/: хэрэглэгчийн өгсөн Монгол/Англи MBTI асуулт, төрлийн өгөгдлөөс гаргасан JSON
- assets/icons/: 16 төрлийн SVG icon

Энэ бүтэц нь номын 2.1–2.5-р бүлгийн router, хуудас салгах, нийтлэг layout, navbar, олон хэлний шийдлийг шинэ сэдэвт хэрэгжүүлсэн.

## Ажиллуулах

Репозиторийн үндсэн хавтсаас npm run dev ажиллуулаад http://localhost:5173/mbti/index.html хаягаар нээнэ.

## Үр дүнг тайлбарлах нь

Энэ асуулга нь өөрийгөө эргэцүүлэх ерөнхий MBTI хэрэгсэл юм. Эмнэлзүйн үнэлгээ, баталгаатай суралцах хэв маягийн онош биш.
